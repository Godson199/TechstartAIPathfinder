Excel • SQL • Power BI • Python — Combined 12-Week Curriculum

Part 1 — Data Analytics Curriculum (Excel, SQL & Power BI)

This course introduces students to the principles and practical
applications of Data Analytics — covering data collection, cleaning,
visualization, interpretation, and reporting. It begins with
spreadsheets (Excel, Google Sheets) and progresses into Structured Query
Language (SQL) and Power BI, preparing learners to extract insights from
structured and unstructured data.

This course is designed to last 12 weeks (3 months). By the end of the
course, students will analyze a real-world dataset and present their
findings in a professional dashboard and presentation slide.

Part 2 — CareerForge Internship + Python for Data Analytics Curriculum
(12 Weeks)

**Program Duration:** 12 Weeks

**Frequency:** 3 Days per Week

**Weekly Schedule:** Monday — Internship work, team collaboration,
sprint planning • Wednesday — Python for Data Analytics class • Friday —
Project execution, presentation, performance review

**Goal:** By the end of the program, interns should be able to use
Excel, SQL, Power BI, and Python to solve real business problems and
become full-stack data analysts.

Organizational Structure

CEO — Responsibilities

- Open the internship with a welcome session.

- Hold bi-weekly leadership talks.

- Review team deliverables.

- Invite industry experts.

- Evaluate final capstone presentations.

- Approve internship projects.

Admin / Program Manager — Responsibilities

- Assign weekly tasks.

- Create deadlines and milestones.

- Track intern performance.

- Coordinate meetings.

- Manage Google Classroom and Workspace.

- Monitor attendance and submissions.

- Lead Friday review meetings.

Interns — Responsibilities

- Attend Python classes.

- Participate in team meetings.

- Complete assigned tasks.

- Submit weekly reports.

- Maintain GitHub repositories.

- Present project updates every Friday.

Weekly Structure

Monday (Work Day) — 2–3 hours

Activities: team stand-up meeting (30 minutes), sprint planning, task
allocation, dataset assignment, team collaboration, documentation
updates.

Deliverables: weekly goals, task breakdown, progress tracker.

Wednesday (Python Class) — 2 hours

Activities: Python lecture, hands-on coding, exercises, Q&A, mini
assignment.

Deliverables: notebook submission, coding exercises.

Friday (Execution & Review Day) — 2–3 hours

Activities: team presentations, code review, business insight
presentation, feedback session, CEO/Admin remarks.

Deliverables: weekly report, GitHub update, team presentation.
